# GoP3 Dataset Capture Tool

Скрипт для быстрого набора датасета скриншотов Governor of Poker 3.

## Установка (один раз)

```bash
pip install mss pillow keyboard pygetwindow
```

## Запуск

```bash
python capture.py
```

Скрипт автоматически найдёт окно GoP3 / BlueStacks / LDPlayer.  
Кадры сохраняются в папку `dataset/` рядом со скриптом.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `SPACE` | Пауза / продолжить |
| `+` / `-` | Интервал +0.5s / -0.5s |
| `S` | Сохранить кадр прямо сейчас |
| `Q` | Выйти |

## Параметры командной строки

```bash
# Кадр каждые 3 секунды, сохранять в папку my_shots/
python capture.py --interval 3.0 --out my_shots

# Выбрать область экрана вручную
python capture.py --region
```

## Советы по сбору датасета

- **Сколько нужно:** 300–500 кадров хватит на хороший старт
- **Разнообразие:** играй на разных столах, снимай префлоп/флоп/тёрн/ривер
- **Интервал:** 2–3 секунды оптимально (много дублей → просто удалишь похожие)
- **После сбора:** загрузи папку `dataset/` на [Roboflow](https://roboflow.com) для разметки
